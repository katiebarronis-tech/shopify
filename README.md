# My Store 7 – Shopify theme

Custom charm bar party theme for My Store 7, built on Shopify's Dawn theme (v16).

- Muted, dusty palette (cream, dusty rose, taupe, sage)
- Homepage: hero, intro, "how a party works", shop, booking call-to-action, FAQ
- Contact page set up as a party booking enquiry form
- English by default, with a language selector for Spanish

## Connect to Shopify

Shopify admin → Online Store → Themes → Add theme → Connect from GitHub →
choose `katiebarronis-tech/shopify`, branch `main`. Preview, then publish when ready.
